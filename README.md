# RefDataKit

Source-aware reference data and tooling designed to support multiple languages and ecosystems.

## Direction

Normalize public and community-maintained sources into a stable, versioned schema, then validate and export the same data for different runtimes. JavaScript and Python are the first targets; future language adapters should consume the shared schema and generated artifacts rather than maintain separate datasets.

The initial data areas may include countries, languages, subdivisions, cities, and educational institutions. Contributions should be reviewed before they become part of a published dataset.

## Data Policy

Every dataset keeps its own source, version, provenance, and license requirements. Do not bundle or redistribute a source until its terms and required attribution are understood. The code and data may have different licenses.

This repository is private during development. No open-source license has been selected yet.

## Status

Initial repository scaffold. Existing application datasets and generators have not yet been copied here.
